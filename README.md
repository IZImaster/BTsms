# BTsms

Send text notes between a Zebra TC52 and a laptop browser over Bluetooth LE.

- **TC52 app** (`app/`): stores notes, Keep-style cards with Copy / Edit / Delete, runs a BLE GATT server.
- **Laptop page** (`docs/index.html`): opens in Chrome / Edge, connects with Web Bluetooth, same cards with Copy buttons.

APK download: https://github.com/IZImaster/BTsms/releases/latest/download/BTsms.apk
Web page: https://izimaster.github.io/BTsms/ (after enabling GitHub Pages: Settings → Pages → Deploy from branch → `main` / `docs`)

Built automatically by GitHub Actions on every push to `main`.
